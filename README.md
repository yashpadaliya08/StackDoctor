# Laravel Doctor

An automated diagnostic, health check, and repair engine for Laravel deployments.

## Quick Start
```bash
# Install CLI globally
pip install -e .

# Scan any Laravel project (from any folder or drive)
laravel-doctor scan C:\path\to\project
laravel-doctor scan E:\projects\hotel.zip
laravel-doctor scan https://github.com/user/repo.git

# Auto-repair project configuration
laravel-doctor fix C:\path\to\project
```
